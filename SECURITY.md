# Security Policy

## Supported Versions

This repository contains personal portfolio configuration and automation workflows. Security updates apply to the active branch.

| Branch | Supported |
| --- | --- |
| `main` | Yes |

## Reporting a Vulnerability

If you discover a security issue or credential exposure in this repository:

1. Send an email directly to `atacanymc@gmail.com` with the subject tag `[SECURITY] AtaCanYmc/AtaCanYmc`.
2. Include a detailed description of the vulnerability, affected files, and reproduction steps.
3. Do not open public GitHub issues or discussions for sensitive security disclosures.

### Response Timeline

- Initial acknowledgment: Within 48 hours.
- Assessment and triage: Within 5 business days.
- Fix deployment: Pushed directly to `main` as soon as remediation is verified.
